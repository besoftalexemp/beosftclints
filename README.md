# BeSoft Customers Website

صفحة HTML/CSS/JavaScript كاملة لعرض عملاء BeSoft مباشرة من ملف Excel.

## مصدر البيانات
ضع ملف العملاء هنا دائمًا بنفس الاسم:

`data/customers.xlsx`

الكود يبحث عن شيت يحتوي الأعمدة التالية:
- `المحافظة`
- `اسم العميل`
- `العنوان`

ويفضّل الشيت المسمى `2` تلقائيًا إذا كان موجودًا.

## تحديث بيانات الموقع
1. افتح ملف Excel الحالي.
2. أضف/عدّل العملاء مع الحفاظ على أسماء الأعمدة كما هي.
3. استبدل الملف الموجود في `data/customers.xlsx` بالنسخة الجديدة.
4. ارفع الملفات على السيرفر مرة أخرى أو استبدل Excel فقط.

لا تحتاج لتعديل HTML أو JavaScript عند إضافة عملاء جدد.

## مهم عند التشغيل
بسبب حماية المتصفح، فتح `index.html` مباشرة من الجهاز (`file://`) قد يمنع قراءة Excel.
شغّل المجلد من Web Server.

### أسهل طريقة للتجربة محليًا
إذا كان Python مثبتًا:

```bash
python -m http.server 8000
```

ثم افتح:

`http://localhost:8000`

أو استخدم VS Code Live Server.

## المكتبة المستخدمة لقراءة Excel
SheetJS عبر CDN:
`https://cdnjs.cloudflare.com/ajax/libs/xlsx/0.18.5/xlsx.full.min.js`

إذا لم يكن الإنترنت متاحًا وقت تحميل الصفحة، سيظهر زر لاختيار ملف Excel يدويًا.

## الملفات
- `index.html` — الصفحة الرئيسية
- `css/styles.css` — تصميم وهوية الصفحة
- `js/app.js` — قراءة Excel، البحث، الفلاتر، الخريطة والإحصائيات
- `data/customers.xlsx` — بيانات العملاء
- `assets/besoft-logo.png` — شعار BeSoft

## الخصوصية
الصفحة تعرض فقط الأعمدة التي طلبتها: اسم العميل، المحافظة، العنوان.
تأكد أن لديك صلاحية نشر بيانات العملاء والعناوين التي ستظهر على موقع عام.
